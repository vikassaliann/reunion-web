Reunion Global

Developer Setup Guide — Website Collaboration

GitHub Repository: https://github.com/vikassaliann/reunion-web.git
Step 1 — Prerequisites (Install Once)
1

Install Node.js (v18 or later)

Download and install from the official website.

https://nodejs.org

Verify: node --version

2

Install Git

Download and install the version control system.

https://git-scm.com

Verify: git --version

3

Install Visual Studio Code

Recommended code editor for the project.

https://code.visualstudio.com
✦
Step 2 — Getting GitHub Access

The repository is public on GitHub. The repo owner will add you as a collaborator so you can push changes directly. Once you receive a collaboration invite on GitHub, accept it — then you're ready to go.

✦
Step 3 — Clone the Project (First Time Only)

Open Terminal (Mac) or Command Prompt (Windows) and run these commands to download the project and install all dependencies:

1

Clone the repository from GitHub

git clone https://github.com/vikassaliann/reunion-web.git
2

Go into the project folder

cd reunion-web
3

Install all dependencies

npm install
4

Start the development server

npm run dev

Open http://localhost:3000 in your browser to see the website.

✦
Step 4 — Making Changes & Pushing to GitHub

Every time you want to make updates, follow this workflow. This pulls the latest code, lets you make edits, and pushes your changes back to GitHub.

1

Pull the latest code from GitHub

Always do this before making any changes to stay in sync.

git pull origin main
2

Make your edits

Open the project in VS Code, edit the files you need, and preview at localhost:3000.

3

Stage all your changes

git add .
4

Commit with a short message describing what you changed

git commit -m "updated about page team photos"
5

Push your changes to GitHub

git push origin main
That's it! Your changes are now on GitHub. The website will update automatically (see below).
✦
Automatic Deployment

🚀 Vercel Auto-Deploy

The live website is connected to Vercel.

↓

Every time you push to the main branch on GitHub,
Vercel automatically builds and deploys the updated website.

↓

No manual deployment needed. Just push and it's live.
